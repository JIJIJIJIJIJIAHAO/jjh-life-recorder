# 📝 生活记录网站

一个简洁优雅的本地生活记录工具，支持日视图、周视图、月视图和统计页面，帮助你记录和管理日常生活。

**在线访问**：https://jijijijijijiahao.github.io/jjh-life-recorder/

## ✨ 功能特性

### 🏠 首页
- **动态渐变背景**：护眼色流动渐变，20秒循环
- **毛玻璃卡片**：苹果风格 backdrop-filter 效果
- **艺术字标题**：从 `quotes.txt` 每日随机选取励志文案
- **图片轮播**：自动展示近3日感悟图片背景
- **自然语言输入**：支持"今天下午一点到三点半，公考刷题，类型为学习"格式
- **本周待办**：支持设置日期和时间，已完成待办默认隐藏
- **数据导入导出**：合并模式，不会覆盖已有数据

### 📅 日视图
- **三列布局**：昨天/今天/明天并排展示，共用24h时间轴
- **时间轴**：6:00开始，0:00-5:00在底部
- **事件色块**：精确对应起止时间，并行事件自动并列
- **快速添加**：点击今天列的空白时段添加日程
- **平滑过渡**：左右方向键切换日期，scroll-snap 吸附

### 📊 周视图
- **连续翻页**：上下滚动查看前后数周，本周高亮
- **事件合并**：同名事件合并显示，最多7条
- **待办事项**：显示每日待办，可点击切换完成状态
- **快速添加**：每天底部有"添加日程"按钮

### 📆 月视图
- **顶部看板**：本月已过x%（小时数计算）、已学习x小时、完成事项x个、待完成x个
- **感悟编辑**：点击日期编辑感悟（30字以内+图片背景）
- **文字自适应**：感悟文字根据长度自动调整字号
- **楷体日期**：日期数字使用楷体，18px加粗

### 📈 统计页面
- **时间分布**：饼图展示前6类活动时长占比
- **体重变化**：折线图展示体重趋势
- **分数记录**：表格展示考试成绩（名称、日期、分数、备注）
- **板块监控**：6张卡片展示总计+5个板块的正确率、做题数、错题数
  - 政治常识、言语理解、数量关系、推理判断、资料分析
  - 列表按时间倒序排列

## 🎨 设计特点

- **毛玻璃效果**：backdrop-filter: blur(20px)
- **动态背景**：linear-gradient 流动渐变
- **弹性动画**：cubic-bezier(0.34, 1.56, 0.64, 1)
- **响应式布局**：适配手机/平板/电脑
- **7种分类标签**：💼工作、🏠生活、📚学习、🏃运动、🍽️饮食、🎮纯玩、📌其他

## 🚀 快速开始

### 本地使用

1. 直接在浏览器中打开 `index.html`
2. 数据自动保存在浏览器 localStorage 中

### 部署到 GitHub Pages

#### 1. 创建 GitHub 仓库

- 访问 https://github.com/new
- 仓库名：`jjh-life-recorder`
- 设为 **Public**
- 不勾选初始化选项

#### 2. 上传代码

```bash
cd jjh-life-recorder
git init
git add .
git commit -m "Initial commit"
git branch -M main
git remote add origin https://github.com/你的用户名/jjh-life-recorder.git
git push -u origin main
```

#### 3. 启用 GitHub Pages

- Settings → Pages
- Source: Deploy from a branch
- Branch: main / (root)
- Save，等待1-2分钟

#### 4. 访问网站

`https://你的用户名.github.io/jjh-life-recorder/`

## 🔄 多设备同步

### 手动导入导出（推荐）

1. **导出**：首页点击"📤 导出数据"，下载 JSON 文件
2. **上传云盘**：将 JSON 文件上传到坚果云/OneDrive/GitHub
3. **导入**：其他设备访问网站后，点击"📥 导入数据"

导入采用**合并模式**：按 ID 去重，新数据补充，同 ID 更新。

## 📝 自然语言输入示例

```
今天下午一点到三点半，公考刷题，类型为学习
明天上午9点到11点半，开会
后天13:00到15:30，看牙医
9月15日 下午二点到四点，健身
```

支持：
- 日期：今天/明天/后天/X月X日
- 时间：一点到三点半/13:00到15:30/1点到3点
- 分类：类型为学习/分类：工作（可选，自动推断）

## 🎨 自定义文案库

编辑 `quotes.txt`，每行一句，系统每日随机选取。
